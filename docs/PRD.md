# 재판정 / Judge Me — PRD (갱신본)

> 이 문서는 인터뷰를 통해 확정된 모든 제품 결정을 반영한 MVP 요구사항 정의서다.

---

## 1. 서비스 개요

- **서비스명**: 재판정 / Judge Me
- **정의**: 품앗이 크레딧 구조 기반 자소서 크라우드 심사 플랫폼
- **핵심 가치제안**: 남을 평가해야 나도 평가받는 구조를 통해, 동일 직군 다수의 "현실적 합의 피드백"을 크레딧으로 획득
- **플랫폼 형태**: 웹 기반 (모바일 앱 아님)
- **기술 스택**: Nuxt.js (Vue 기반) + TypeScript, 관리형 PaaS 배포, 관리형 PostgreSQL

### 1-1. 기존 서비스 대비 포지셔닝

| 구분        | AI 첨삭 (챗GPT 등) | 유료 1인 첨삭 (잡코리아 등) | 재판정         |
| --------- | -------------- | ----------------- | ----------- |
| 비용        | 무료~저가          | 고가                | 크레딧(품앗이)    |
| 현실 감각     | 낮음             | 높음 (편향 가능)        | 높음 (다수 합의)  |
| 개성 반영     | 낮음(정답화 경향)     | 중간                | 높음          |
| 평가자 수     | -              | 1인                | 3인 (소프트 보장) |

## 2. 핵심 메커니즘

### 2-1. 품앗이 크레딧 구조

| 이벤트                  | 크레딧 변동 | 비고                    |
| -------------------- | ------ | --------------------- |
| 신규가입                 | +5     | 무료 크레딧, 유효기간 무기한      |
| 자소서 1건 등록            | −3     | 등록 시점에 차감, 잔액 부족 시 불가 |
| 평가 1건 완료(완결성 검증 통과)  | +1     | 제출 즉시 지급, 조건부 없음      |

**확정 정책:**
- 지급된 크레딧은 사후 환수(clawback)하지 않는다.
- 크레딧 만료 로직은 채택하지 않는다(유효기간 무기한).
- pending 상태 없음 — 평가 제출 즉시 +1 지급.
- 크레딧 이중 차감 방지는 DB 트랜잭션 + 원자적 업데이트로 처리한다.

### 2-2. 직군·연차 태그 및 매칭 로직

#### 직군 태그 (확정 enum)

| 대분류   | 소분류                                       |
| ----- | ----------------------------------------- |
| 개발    | 프론트엔드 / 백엔드 / 풀스택 / 모바일 / 데이터·AI / DevOps·인프라 |
| 디자인   | UX·UI / 그래픽·브랜딩 / 프로덕트 디자인               |
| 마케팅   | 퍼포먼스 / 브랜드·콘텐츠 / 그로스                      |
| 기획    | 프로덕트 기획 / 서비스 기획                          |
| 영업    | 영업 / 비즈니스 개발                              |
| HR    | 채용 / 인사·조직문화                              |

#### 연차 태그 (확정 enum)

`신입` / `1~3년` / `4~7년` / `8년+`

#### 매칭 큐 규칙

- **pull 방식**: 평가자가 큐에서 직접 가져간다(push 자동배정 없음).
- **FIFO 강제**: 노출 순서는 등록 시각 기준 선입선출이며, 평가자의 임의 정렬·검색·체리피킹 불가.
- **태그 필터**: 평가자의 직군(대분류·소분류) + 연차 태그와 일치하는 제출물만 노출.
- **0건 시 빈 큐**: 일치 태그 제출물이 없으면 인접 태그 폴백 없이 빈 큐로 대기.
- **동시성 처리**: DB 원자적 쿼리(`SELECT FOR UPDATE SKIP LOCKED`)로 경합 처리.
- **채택하지 않은 옵션**: push 자동배정, 인접 태그 폴백, 시딩 코호트 예외, 배치 웨이브 온보딩.

#### 3인 소프트 보장

- 제출물 1건당 평가자 3인을 목표로 한다.
- 진행률은 "N/3 평가 완료"로만 표시하며, SLA 타이머·자동 환불·캐리오버 로직은 MVP 범위 밖.
- 정체 건은 수동/CS 대응한다.

### 2-3. 평가 방식 및 완결성 검증

**정량 평가 (5점 척도, 4축 모두 필수):**
1. 직무적합성
2. 논리구조
3. 구체성(숫자·사례)
4. 가독성

**정성 코멘트:** 50자 이상 필수.

**완결성 검증:** 4축 정량 전부 입력 + 코멘트 50자 이상을 제출 시점에 동기 검증한다. 통과 시 즉시 크레딧 +1 지급.

## 3. 신뢰도 시스템

### 3-1. 정확도 점수 — MVP 범위 밖

- 기존 안: 합격 여부 사후 확인으로 안목 레벨 측정
- **결정**: 데이터 축적 기간이 필요하고 입력률 저조 예상. MVP에서는 채택하지 않으며 v2 이후 반영.

### 3-2. 신뢰 점수 시스템

- 측정 시점: 평가 직후 제출자의 즉시 체크리스트 응답
- 용도: 매칭 큐 노출 순서 + 신뢰 점수 산정에만 영향
- **크레딧과 완전히 분리**: 체크리스트 결과가 크레딧 지급 여부에 영향을 주지 않는다.

### 3-3. 즉시 신뢰점수 체크리스트

제출자가 평가를 받은 뒤 응답하는 행동 기반 사실 질문 3항:

1. 평가자가 구체적 사례·숫자를 지적하였는가 (예/아니오)
2. 내가 미처 생각하지 못한 관점을 제시하였는가 (예/아니오)
3. 실행 가능한 대안을 제시하였는가 (예/아니오)

이 응답은 신뢰 점수와 큐 노출 순서에만 영향을 주며, 크레딧 지급과 무관하다.

## 4. MVP 기능 범위

| 기능                     | MVP 포함 | 비고                                 |
| ---------------------- | ------ | ---------------------------------- |
| 회원가입 및 직군·연차 태깅        | ✅ 필수   | 가입 즉시 크레딧 5점 지급                   |
| 자소서 등록(텍스트)            | ✅ 필수   | 파일 업로드는 후순위                        |
| 크레딧 시스템                | ✅ 필수   | 원장 방식, 환수·만료 없음                    |
| 평가 매칭 큐                | ✅ 필수   | FIFO + 태그 필터, pull 방식              |
| 4축 정량평가 및 코멘트(50자+)    | ✅ 필수   | 완결성 동기 검증, 즉시 크레딧 지급               |
| 즉시 신뢰 점수(체크리스트)        | ✅ 필수   | 크레딧과 분리, 노출 순서에만 영향               |
| PII 경고(정규식 기반, 비차단)    | ✅ 필수   | 이메일·전화번호·URL만 감지, 자동 마스킹 없음       |
| 우선매칭권(유료, 24시간 SLA)    | ✅ 필수   | 사용자당 동시 활성 1건 상한                  |
| 정확도 점수(합격 여부 사후검증)     | ❌ 후순위  | 데이터 축적 후 v2                        |
| 실시간 알림                 | ❌ 후순위  | 이메일 다이제스트로 대체                      |
| AI 성의없음 필터             | ❌ 후순위  | 초기엔 신고 기능으로 대체                     |
| NER 기반 자동 이름·기관 마스킹    | ❌ 범위 밖 | 마스킹 책임은 작성자에게 있음                  |
| 크레딧 만료 로직              | ❌ 범위 밖 | 채택하지 않음                            |
| 인접 태그 폴백               | ❌ 범위 밖 | 채택하지 않음                            |
| push 자동배정              | ❌ 범위 밖 | 채택하지 않음                            |
| 시딩 코호트 예외              | ❌ 범위 밖 | 채택하지 않음                            |
| 배치 웨이브 온보딩             | ❌ 범위 밖 | 채택하지 않음                            |

**개인정보 마스킹 정책:**
- 본문 식별정보 마스킹 책임은 작성자에게 있다.
- 시스템은 '완전 익명 보장' 표현을 사용하지 않는다.
- PII 경고는 이메일·전화번호·URL 등 고신뢰도 정규식 패턴에 한정하며, 비차단(non-blocking) 경고로만 제공한다.
